# 🎓 UniVerse – University Management System

UniVerse is a Database Management System (DBMS) project designed to manage university-related information, including students, faculty, departments, courses, attendance, examinations, fees and academic records.

The project uses MySQL for database management and HTML, CSS and JavaScript for the frontend interface.

## 📌 Project Overview

The main objective of UniVerse is to organize university data systematically and provide a simple interface to view and manage academic information.

## ✨ Features

- Dashboard with university statistics
- Student management
- Faculty management
- Department management
- Course management
- Attendance records
- Examination management
- Result management
- Fee management
- Timetable management
- Search functionality across sections

## 🗄️ Database Design

Database Name: `universe_db`

The database consists of 13 tables:

1. department
2. semester
3. classroom
4. student
5. faculty
6. course
7. enrollment
8. teaching_assignment
9. examination
10. fee
11. attendance
12. result
13. timetable

The database includes primary keys, foreign keys, constraints and relationships between different entities.

## 🚀 How to Run

### Database Setup
1. Open MySQL Workbench.
2. Execute the database creation SQL script.
3. Execute the table creation scripts.
4. Execute the sample data insertion script.
5. Verify the database and tables.

### Frontend Setup
1. Open the Frontend folder in VS Code.
2. Open `index.html`.
3. Run it using Live Server or open it directly in a browser.
4. Explore the dashboard and different management sections.

## ⚠️ Current Project Status

The MySQL database and frontend interface have been developed separately.

The frontend currently uses sample demonstration records through JavaScript. A backend API connection to MySQL has not yet been implemented.
